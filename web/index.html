Como ler as métricas
Primeiro texto (TTFT visível)
Tempo até começar a resposta visível. TTFT é o tempo até o primeiro token; aqui o início do texto é observado pelo cliente.
Primeiro conteúdo
Tempo até o primeiro conteúdo recebido; pode incluir raciocínio antes do texto visível.
Entrada / saída / cache
Entrada é o pedido processado; saída é a geração. Cache é parte da entrada e não é somado novamente ao total de tokens.
Total medido / total Ollama
Total medido é a duração observada pelo cliente Python; total Ollama é a duração informada pelo servidor. Incluem etapas e limites de medição diferentes.
Carga / prompt
Carga mede carregar o modelo; prompt mede processar a entrada, conforme informado pelo Ollama.
Geração / tokens por segundo
Geração é o tempo de produzir a saída. Tokens/s divide os tokens de saída pela duração de geração, sem avaliar a qualidade da resposta.
