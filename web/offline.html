Inicie o servidor local

O aplicativo está instalado, mas o servidor Python não está acessível neste endereço.

Inicie o app e o Ollama no computador. Depois, abra novamente esta página.

Linux: python3 app.py
Windows: py -3 app.py
Docker Linux: docker compose -f compose.linux.yaml up -d

Tentar novamente

A instalação não inicia os servidores automaticamente. Prompts, respostas, exportações e tokens não são guardados no cache da PWA.
